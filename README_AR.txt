# ICT بالعربي 3.6 — إدارة وحذف المنشورات من لوحة النشر

## الجديد
- يظهر زر **حذف** بجانب كل تحليل وتوصية في صفحة `admin.html`، بعد اتصال صاحب الموقع برمز GitHub ذي صلاحية الكتابة.
- قبل التنفيذ تظهر رسالة تأكيد تحمل اسم المنشور ونوعه.
- بحث بالعنوان/الأصل المالي، وتصفية: الكل، التحليلات، التوصيات.
- قراءة أحدث نسخة من ملف JSON ومقارنتها بالمنشور المحدد قبل الحذف؛ يمنع حذف عنصر آخر عند تغيير البيانات أو وجود نسخ متطابقة.
- يعتمد الحذف على GitHub Contents API مع SHA الصحيح. إذا حدث تعارض أو فقد الاتصال يفشل بأمان.
- الحذف من `recs.json` أو `analyses.json` فقط. **لا يحذف صورة الشارت** ولا يُرسل إشعارات جديدة.
- يمكن استعادة المحتوى من سجل GitHub إذا لزم الأمر، ولا توجد سلة محذوفات مخصصة في اللوحة.

## طريقة التركيب
1. افتح مستودع `IsmaeilMoh/ictbelaraby` على GitHub.
2. ارفع الملفات الثلاثة الموجودة **داخل** هذه الحزمة إلى جذر المستودع واستبدل القديمة فقط:
   - `admin.html`
   - `admin.js`
   - `admin.css`
3. احفظ التغييرات باستخدام Commit changes.
4. افتح `https://ismaeilmoh.github.io/ictbelaraby/admin.html` وحدّث الصفحة تحديثًا كاملًا (`Ctrl + F5`).
5. أدخل GitHub token الحالي، جرّب فلترة المنشورات، ثم اضغط حذف على منشور غير مطلوب مع تأكيد العملية.

## ملفات لا تلمسها
لا تستبدل `recs.json` ولا `analyses.json` بأمثلة من أي حزمة. كذلك لا تغيّر `app.js` أو `push.js` أو `push-config.js` أو مجلدات `.github` و`scripts` أو ملفات الأسواق والأخبار. لا يتطلب التحديث تعديل OneSignal أو مفاتيحه.

## ملاحظات الأمان
- زر الحذف موجود في لوحة النشر فقط، وليس في الموقع العام. معرفة عنوان `admin.html` لا تمنح صلاحيات؛ يتطلب الحذف رمز GitHub بصلاحية Contents: Read and write.
- نافذة التأكيد لا تستطيع إلغاء عملية اكتملت؛ الاستعادة تتم باستخدام سجل GitHub.
- لا تحذف الصور آليًا حتى لا تتعطل روابط في منشورات أخرى.
- GitHub Pages/CDN قد يتأخر قليلًا في إظهار التغيير؛ عند الحاجة أعد تحميل الصفحة.
