إصلاح تشخيص اشتراك OneSignal — ICT بالعربي

ارفع ملفي push.js و sw.js فقط إلى جذر مستودع ictbelaraby على فرع main واستبدل النسختين القديمتين.
لا تغير push-config.js الذي يحتوي على App ID الخاص بك، ولا ملفات التحديث أو بيانات الأسواق.
بعد اكتمال نشر GitHub Pages افتح الموقع من نافذة جديدة ثم اضغط الاشتراك في إشعارات الخلفية.
ستظهر رسالة نجاح موثقة بوجود PushSubscription ID أو سبب المشكلة إن فشلت التهيئة.
إذا ظهر نجاح، افحص Audience > Subscriptions في OneSignal.
تذكير: اشتراك الجهاز لا يعني أن إرسال الإشعارات من GitHub Actions يعمل بعد؛ يحتاج إعداد REST API Key كـGitHub Secret واختبار الإرسال.
