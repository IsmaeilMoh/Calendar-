# ICT بالعربي 5.4.1 — مركز تداول مضغوط

## ما الجديد؟
- نقل شريط «أدوات المتداول» الموحد إلى **فوق مركز التداول مباشرة في الصفحة الرئيسية**، بدل ظهوره تحت رأس الموقع.
- الإبقاء على الشريط في مكانه المعتاد تحت الرأس عند الانتقال إلى صفحات الأدوات المستقلة، وعلى أقسام الموقع الأخرى.
- إعادة تنسيق بطاقات مركز التداول الحالية (11 رابطًا) في **شبكة مدمجة**: ثلاثة أعمدة على اللابتوب، وعمودان على الأجهزة الأضيق، وعمود واحد على الشاشات الصغيرة جدًا.
- كل بطاقة تعرض أيقونة صغيرة، واسم القسم، ووصفًا من سطر واحد، مع تقليل ارتفاع البطاقة والمسافات.
- روابط الأقسام ووظائفها كما كانت؛ لا تعديل على المحتوى أو مصادر الأسعار والإشعارات.

## التثبيت على GitHub
1. افتح مستودع `IsmaeilMoh/ictbelaraby` واحتفظ بنسخة احتياطية.
2. **استبدل هذه الملفات الأربعة فقط** في جذر المستودع:
   - `index.html`
   - `platform.js`
   - `platform.css`
   - `sw.js`
3. اعمل Commit وانتظر اكتمال النشر.
4. افتح الصفحة الرئيسية واضغط `Ctrl + Shift + R`.
5. جرّب الانتقال إلى الأسواق ثم العودة إلى الرئيسية؛ يجب أن يعود الشريط إلى أعلى مركز التداول، وتبقى البطاقات مدمجة.

## مهم
- لا تلمس `app.js` أو `style.css` أو ملفات JSON أو `admin.*` أو إعدادات OneSignal.
- لم أغير أي وظيفة أو رابط من روابط بطاقات مركز التداول.
- هذا تحديث تصميم/ترتيب فقط، ولم يتضمن إنشاء أصول أو إشارات تداول جديدة.
