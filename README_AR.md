# ICT بالعربي 4.4 — Trader Suite

إصدار واحد يضيف ثلاثة تطويرات دون استبدال ملفات البيانات أو كسر الأسعار المباشرة والإشعارات:

1. **لوحة المتداول اليومية**: أسفل بطاقات المقدمة وMarket Pulse؛ تبيّن نافذة ICT الحالية، الخبر القوي القادم من الأجندة الحديثة، عدد التوصيات المنشورة المعلّقة والنشطة، وأحدث تحليل منشور. إذا لم تتوفر بيانات، تظهر حالة توضيحية بدل أرقام غير حقيقية.
2. **Smart Trade Center**: حالات `pending`, `open`, `tp`, `sl`, `cl`, `cancelled`، ونسبة العائد إلى المخاطرة الحسابية حيث تسمح الأرقام، وعدّاد التوصيات والنتائج؛ يعتمد النجاح فقط على النتائج التي أدخلها الناشر بنفسه، وليس سعرًا آليًا مفترضًا.
3. **ICT Smart Sessions**: شبكة جلسات مع أزرار تصفية، والوقت في نيويورك، وتحويل بداية الجلسة إلى المنطقة الزمنية المختارة، وعدّاد حتى البداية أو النهاية. تراعي انتقال التاريخ والجلسات العابرة لمنتصف الليل.

## تركيب التحديث

من أرشيف ZIP، استبدل في **جذر** مستودع GitHub هذه الملفات الستة فقط:

- `app.js`
- `style.css`
- `sw.js`
- `admin.js`
- `admin.html`
- `admin.css`

**لا تستبدل أو تمسح**:

- `recs.json`, `analyses.json`, `market-movers.json`, `news-live.json`, `calendar-live.json`
- `push-config.js`, `push.js`, المجلد `push/`
- `.github/`, `scripts/`, `market-icons/`, `analysis-images/`
- `logo-original.jpeg`

بعد Commit، افتح الموقع وأعد تحميله `Ctrl + Shift + R` على الكمبيوتر. افتح لوحة الإدارة `admin.html`، واتصل برمز GitHub السابق. عند تحرير توصية ستجد حالات إضافية وخانة **تحديث النتيجة**. احفظ التعديل وتحقق من ظهوره في قسم التوصيات.

## اختبارات القبول

- الرئيسية: ظهور Market Pulse الأصلي دون تغيير، ثم لوحة المتداول اليومية أسفله.
- التوصيات: وجود فلاتر معلّقة ومفعّلة وملغاة، وإظهار نتائج الصفقات الموثقة.
- الإدارة: تحرير توصية اختبار، ثم تغيير حالتها إلى «بانتظار التفعيل» وتدوين ملاحظة نتيجة؛ التحقق من ظهورها بالموقع.
- أدوات ICT: اختيار كل جلسات / Kill Zones / Silver Bullet، والتحقق من العدادات وتوقيت الجهاز.
- موبايل: ظهور البطاقات دون تمرير أفقي مزعج.
- لا يتطلب هذا الإصدار تشغيل أي Workflow إضافي أو إضافة Secrets.

## القيود والشفافية

- لا تُراقَب أسعار الأصول آليًا لتحديد بلوغ الهدف أو وقف الخسارة؛ تحديث حالة الصفقة مسؤولية الناشر.
- نسبة النجاح تحسب فقط حالات TP وSL المنشورة، ولا تعبر عن عائد محفظة أو توقع أداء.
- البيانات الإرشادية للنوافذ قد تختلف بين مدارس ICT. يمكن تفعيل التنبيهات المحلية والإشعارات الحالية بالطريقة السابقة.
- اختُبرت صياغة JavaScript وسلامة ملفات ZIP، لكن يلزم اختبار وظيفي على GitHub Pages بعد النشر.
