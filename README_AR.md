# ICT بالعربي 6.3 — موثوقية البيانات والأداء والأمان

## ملفات التحديث (7 ملفات)
استبدل في جذر المستودع: `index.html`, `app.js`, `platform.css`, `sw.js`.
أضف في جذر المستودع: `trust.html`, `trust.css`, `trust.js`.
المجموع **7 ملفات**. لا تغيّر أي ملف بيانات أو أي ملف إداري أو OneSignal.

## وظائف الإصدار
- إضافة مركز موثوقية مستقل: `/trust.html`.
- فحص 7 مصادر عامة: أسعار دورية، أخبار حية، أجندة حية، توصيات، تحليلات، روابط، أجندة مرجعية.
- إظهار نجاح جلب الملف، تنسيق البيانات، عدد السجلات، عمر التحديث إذا وُجد، وزمن التحميل من الجهاز.
- مقارنة البيانات الحية بحدود زمنية متوافقة مع الإصدار السابق: الأسواق 6 ساعات، الأخبار 4 ساعات، الأجندة 24 ساعة.
- عدم اعتبار الملفات الثابتة قديمة لمجرد غياب `updatedAt`.
- تقليل طلبات التحميل التمهيدي المتزامنة في `sw.js`، وإصلاح إعادة العرض دون اتصال لتجنب عرض الرئيسية بدلاً من الصفحة المطلوبة.
- جميع JSON (باستثناء manifest) تُطلب من الشبكة فقط، ولا تُعاد نسخة مخزنة للبيانات المالية المتغيرة.
- ملاحظات أمان واضحة حول رمز GitHub والإدارة وسجلات المتداول. **هذا ليس تدقيق اختراق شاملًا.**

## التثبيت
1. احفظ نسخة احتياطية.
2. ارفع الملفات السبعة إلى جذر مستودع GitHub، مع الاستبدال للأربعة القديمة.
3. لا ترفع أو تعدّل ملفات JSON أو ملفات OneSignal أو مجلد `.github` أو ملف الإدارة.
4. بعد اكتمال GitHub Pages افتح الرئيسية ثم `trust.html`، واضغط `Ctrl + Shift + R`.
5. جرّب آخر خبر ومواعيد الأجندة وإظهار حالة عدم توفر شبكة قبل الاعتماد على النتيجة.

## حدود يجب معرفتها
- مركز الفحص يعمل من المتصفح الذي فتح الصفحة فقط؛ لا يوجد مراقب مركزي أو مراقبة تشغيلية مستمرة 24/7.
- بعض البيانات غير الفورية قد تظهر قديمة، وهذا مقصود.
- لا يضمن فحص JSON صحة الأرقام عند مصدر السوق ولا خلو الخادم من مشاكل التراخيص.
- لا قياس Core Web Vitals عبر جمهور الزوار ولا اختبار اختراق فعلي؛ يلزم أدوات وخدمات إضافية لهما.
- بيانات الـTrader DNA والمسودات القديمة لا تُعدَّل أو تُمس.
