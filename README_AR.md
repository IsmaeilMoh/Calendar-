# ICT بالعربي — الإصدار العصري

## رفع الموقع إلى GitHub Pages

1. فك الضغط عن ملف ZIP.
2. ارفع **محتويات** المجلد مباشرة إلى جذر مستودع `ictbelaraby` (لا ترفع المجلد كطبقة إضافية).
3. من GitHub → Settings → Pages اختر Deploy from a branch ثم `main` و `/(root)`.
4. زر الموقع على `https://ismaeilmoh.github.io/ictbelaraby/`.
5. لو ظهرت نسخة قديمة بسبب التخزين المؤقت، أغلق التطبيق المثبت وأعد تحميل الموقع ثم أعد فتحه.

## إدارة المحتوى

- `news.json`: الأخبار.
- `recs.json`: التوصيات. البيانات الموجودة حاليًا **أمثلة** وليست توصيات حقيقية.
- `links.json`: روابط التواصل. تم تصحيح حقل رابط تلجرام إلى `url`.
- `agenda.json`: بيانات الأجندة الأسبوعية. **تتضمن البيانات المعلنة للأسبوع 16–22 نوفمبر 2026 فقط**؛ ليست تحديثًا آليًا أو نتائج مباشرة.
- `style.css`: الألوان والخطوط والعناصر المرئية.
- `app.js`: الواجهة والقوائم والفلاتر.
- `sw.js` و `manifest.json`: تثبيت PWA والعمل الأساسي دون إنترنت بعد زيارة أولى.
- `logo-original.jpeg`: شعار المستخدم كما أرسله. `icon-192.png` و`icon-512.png` مشتقان منه بالحجم المخصص لأيقونات النظام.

## تنبيهات

- شريط TradingView يتطلب الإنترنت ويعتمد على الخدمة الخارجية.
- موقع GitHub Pages ثابت؛ لتحديث بيانات الأجندة آليًا يلزم ربط مصدر بيانات أو GitHub Actions لاحقًا.
- تأكد من مراجعة نتائج الأحداث والتواريخ قبل النشر أو التداول.
- تصميم مستوحى من نهج التحرير والبساطة في Bloomberg وMowjah بدون نسخ عناصرهما المحمية أو علاماتهما.
