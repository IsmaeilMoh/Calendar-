# ICT بالعربي 6.8 — Splash Patch (RTL Line)

هذه **حزمة تحديث جزئية** مبنية لإضافة شاشة الافتتاح المعتمدة إلى إصدار **ICT_Arabic_6.8_READY_TO_UPLOAD**.

> **مهم:** بما أن ملف 6.8 الكامل غير موجود داخل بيئة العمل الحالية، فهذه الحزمة ليست نسخة كاملة جديدة من الموقع، بل **Patch آمن** تضيفه فوق 6.8.

## محتويات الحزمة
- `splash.css`
- `splash.js`
- `logo-transparent.png`
- `index_snippet.html`

## المطلوب في مستودع GitHub
1. ارفع الملفات الثلاثة التالية إلى **جذر الموقع**:
   - `splash.css`
   - `splash.js`
   - `logo-transparent.png`

2. افتح ملف `index.html` في إصدار 6.8.

3. انسخ الأكواد من ملف `index_snippet.html` وضعها كما هو موضح بداخله:
   - سطر CSS داخل `<head>`
   - بلوك شاشة الافتتاح مباشرة بعد `<body>`
   - سطر JavaScript قبل `</body>`

## المعاينة داخل المتصفح
بعد الرفع يمكنك تجربة الحركة داخل المتصفح عبر:
`?splash=1`

مثال:
`https://ismaeilmoh.github.io/ictbelaraby/?splash=1`

## ما الذي تفعله الحركة؟
- الشعار المفرغ ينبثق من الأسفل إلى الأعلى.
- خط التحميل أسفل الشعار مع **مسافة أكبر** ويتحرك **من اليمين إلى اليسار**.
- تظهر الحركة تلقائيًا عند فتح تطبيق PWA المثبّت، أو داخل المتصفح عند استخدام `?splash=1`.

## ملاحظة مهمة
شاشة أندرويد الأصلية التي تظهر قبل تحميل صفحة الويب قد تستمر في عرض أيقونة التطبيق بالطريقة التي يفرضها النظام. هذه الحزمة تتحكم في **شاشة الافتتاح داخل الموقع بعد بدء تحميل الصفحة**.
