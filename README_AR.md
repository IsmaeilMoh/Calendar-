# ICT بالعربي 6.5 — تجربة الموبايل

## ماذا يقدم هذا التحديث؟
- شريط تنقل سفلي للموبايل في صفحات الأدوات والأصول. **الرئيسية تحتفظ بشريطها الأصلي**؛ فلا يظهر شريطان في الوقت نفسه.
- قائمة «المزيد» تفتح اختصارات الأدوات، وتدعم اللمس ولوحة المفاتيح وزر Escape.
- تحسين المسافات وأحجام الأزرار وحالات التمرير الأفقي للجداول والفلاتر.
- غرفة العمليات تصبح أكثر تراصًا في الهاتف، مع الإبقاء على اختصارات مركز التداول المضغوطة.
- الحفاظ على ارتفاع شارتات TradingView من إصلاح 6.1.2.
- التعامل مع مساحة أزرار الهاتف السفلية (safe-area) والتقليل من الحركة عند اختيار Reduced Motion.
- تحديث كاش الـPWA ليضم ملفات الموبايل الجديدة.

## التركيب
ارفع محتويات الحزمة إلى **جذر مستودع GitHub Pages** مع الاحتفاظ ببنية المجلدات كما هي:
- جديد: `mobile.css` و`mobile.js`.
- استبدل: `index.html` و`workspace.html` و`intelligence.html` و`research.html` و`smart-desk.html` و`workflow.html` و`trust.html` و`assets.html` و`analytics.html` و`sw.js`.
- استبدل صفحات HTML الخمس عشرة داخل مجلد `assets/`، دون حذف المجلد أو تغيير أسماء الأصول.

**لا تغيّر:** `app.js` و`style.css` و`platform.css` و`platform.js` أو ملفات JSON أو ملفات OneSignal أو بيانات المتداول أو ملفات لوحة الإدارة.

## فحص يدوي بعد الرفع
1. افتح الرئيسية على هاتف: يجب ظهور الشريط السفلي المعتاد فقط.
2. افتح `assets/XAUUSD.html`: شارت بعرض كامل، وأسفل الشاشة تنقل جديد؛ قائمة «المزيد» تعمل.
3. افتح `workspace.html` و`workflow.html` و`smart-desk.html`: راجع أن آخر الحقول والأزرار لا تختبئ خلف الشريط السفلي.
4. افتح `research.html` و`intelligence.html` و`trust.html`: فلاتر قابلة للتمرير عند الحاجة دون تمرير الصفحة أفقيًا.
5. جرّب الوضع الداكن والعودة للرئيسية، ثم اعمل تحديثًا قويًا (Ctrl+Shift+R) عند الحاجة.

**مهم:** هذا تحديث واجهة واستجابة فقط، وليس تعديلًا لمصادر الأسعار أو نموذج الصفقات أو إعدادات Plausible.
