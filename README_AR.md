# ICT بالعربي 6.0 — غرفة عمليات الصفحة الرئيسية

هذا التحديث يطوّر الصفحة الرئيسية لتصبح **غرفة عمليات تداول** واضحة ومركزة.

## ما الذي تغيّر؟
- إضافة قسم جديد باسم **غرفة عمليات الصفحة الرئيسية** تحت واجهة الأخبار والسوق مباشرة.
- 6 بطاقات عملية تعرض:
  - نافذة ICT الحالية أو القادمة
  - الخبر الاقتصادي القوي القادم مع عدّ تنازلي
  - حالة التوصيات ونسبة النجاح الموثقة
  - أحدث تحليل منشور
  - الخبر الأبرز
  - أقوى أصل حركةً من لقطة السوق الأخيرة
- تحسين بصري للبطاقات مع تصميم زجاجي/فحمي متسق مع هوية الموقع.
- تحديث رقم الإصدار الظاهر في التذييل إلى **6.0**.
- تحديث `sw.js` لضمان تحميل النسخة الجديدة وعدم بقاء المستخدم على كاش قديم.

## الملفات داخل الحزمة
استبدل الملفات التالية فقط:
- `index.html`
- `app.js`
- `platform.css`
- `platform.js`
- `sw.js`

## ملاحظات
- لا تعدّل `style.css` أو ملفات البيانات أو ملفات OneSignal.
- بعد الرفع إلى GitHub، افتح الموقع ثم نفّذ **Ctrl + Shift + R**.
- إذا لم يظهر التغيير، أغلق التبويب وافتحه من جديد، أو امسح بيانات الموقع من المتصفح.
