# ICT بالعربي — إصلاح 4.3.1 للبطاقتين

## لماذا لم يتغير شكل اللوحة؟
تحققت من ملفي `app.js` و`style.css` المنشورين، وتعديل 4.3 موجود بالفعل. لكن شرط عرض داخل CSS كان يحوّل البطاقتين إلى عمود واحد عند ضيق عرض لوحة Market Pulse نفسها، وليس فقط عند ضيق شاشة الجهاز. كذلك يحتفظ الموقع بنسخة مخزنة عبر Service Worker.

## الإصلاح
- على اللابتوب (عرض النافذة أكثر من 760px): البطاقتان جنب بعض في صف واحد، ومحتوى كل بطاقة عمودي وخطه أكبر.
- على الهاتف: البطاقتان تحت بعض لتجنب قص الكلمات.
- تحديث اسم ذاكرة الموقع المؤقتة ليتسلم الزوار CSS الجديد.

## ارفع الملفين فقط إلى جذر المستودع
- `style.css`
- `sw.js`

بعد Commit افتح الموقع؛ جرب Ctrl+Shift+R أو في نافذة خاصة. إن كنت تشغل الموقع كتطبيق PWA أغلقه ثم أعد فتحه. لا ترفع app.js أو ملفات JSON من إصدار قديم.
