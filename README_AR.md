# ICT بالعربي 5.0 — المرحلة الأولى: مساحة المتداول الشخصية

هذا التحديث مبني على ملفات الإصدار 4.5 ولا يبدل تصميم Market Pulse، ولا يلمس الأسعار أو الأخبار أو التوصيات أو التحليلات أو إدارة النشر أو OneSignal.

## ما الجديد؟

1. **My Trading Terminal** — لوحة شخصية فيها بطاقات الأدوات وروابط الأقسام الحالية، ويمكن إظهارها/إخفاؤها وتحريك ترتيبها باستخدام الأسهم الصغيرة. اسم اللوحة والأصل المفضل والوقت الحالي في نيويورك.
2. **Prop Firm Guardian** — حاسبة محلية للسحب اليومي والإجمالي، بنموذج حد ثابت أو حد متحرك ومرجع يدوي. تعرض الحدود والمتبقي وتأثير المخاطرة المخططة. ليست مرتبطة بالوسيط وليست مراقبة مباشرة للحساب.
3. **Pre-Trade Checklist** — شروط ICT ومراجعة الأخبار والمخاطرة والالتزام بالخطة، مع شروط إضافية وحفظ آخر 15 مراجعة.
4. **نسخ احتياطي** بصيغة JSON ونقل الإعدادات بين الأجهزة يدويًا. البيانات مخزنة في localStorage الخاص بالمتصفح.

## ارفع هذه الملفات الخمسة في جذر مستودع ictbelaraby

- `app.js` **استبدال** — يضيف رابط «مساحتي» إلى الرئيسية وقسم المزيد.
- `sw.js` **استبدال** — لتحديث ذاكرة التخزين المؤقت واستباق تحميل الصفحة الجديدة.
- `workspace.html` **ملف جديد** — الواجهة الشخصية.
- `workspace.css` **ملف جديد** — التصميم.
- `workspace.js` **ملف جديد** — الوظائف وحفظ البيانات.

لا ترفع README إلى الموقع إلا إذا رغبت في ذلك. **لا ترفع أي ملفات JSON للبيانات**. لا تغيّر `index.html` أو `admin.*` أو `.github` أو `scripts` أو OneSignal.

## فتح الصفحة

بعد اكتمال GitHub Pages:

`https://ismaeilmoh.github.io/ictbelaraby/workspace.html`

أو اضغط «مساحتي الخاصة» في «مركز التداول» بالصفحة الرئيسية، أو «مساحتي» في «المزيد».

## الاختبار

1. افتح «مساحتي» وتأكد من وجود ثماني بطاقات. اخفِ بطاقة، انقل بطاقة، ثم أعد تحميل الصفحة وتأكد من حفظ التغييرات.
2. جرّب الحارس بقيم اختبار: رصيد ابتدائي 5000، حالي 4900، Equity 4800، بداية اليوم 5000، حد يومي 5%، إجمالي 10%، مخاطرة الصفقة 50. وفق هذه القاعدة الافتراضية ستكون المسافة اليومية المتبقية 50، والإجمالية 300. تأكد من عدم استخدام هذه الأرقام في التداول الحقيقي إلا إذا كانت قواعد شركتك تطابقها.
3. افتح قائمة المراجعة، ضع علامة على شرطين، ثم اضغط حفظ بعد إدخال المخاطرة وتأكد من ظهورها في السجل.
4. نزّل النسخة الاحتياطية، ثم تحقق من استيرادها بنجاح في متصفح تجريبي.
5. جرّب الموبايل وتأكد من أن الأدوات تقرأ جيدًا على الشاشة.

## الحدود والأمان

- لا نسأل عن كلمة مرور حساب التداول أو API Keys؛ لا توصل أداة الحارس بأي حساب خارجي.
- التخزين محلي فقط وغير مشفر داخل متصفح المستخدم؛ تجنب إدخال أسرار شخصية. مسح بيانات المتصفح يمسحها أيضًا إذا لم تصدّر نسخة احتياطية.
- لا يتم إصدار إشارات تلقائية ولا تنفيذ صفقات.
- أسعار TradingView الموجودة في الموقع لا تدخل حساب حدود Prop Firm تلقائيًا.
- تصنيف الحارس **تقديري فقط**: قواعد السحب اليومية والمتحركة تختلف حسب الشركة، وتحتاج ضبطًا يدويًا دقيقًا، بما في ذلك قاعدة منتصف الليل أو Equity/Balance المستخدمة فعليًا.
- الحارس في هذا الإصدار يدعم نموذجين عامين (ثابت/متحرك) وليس كل القواعد المعقدة لبعض الشركات.
