# ICT بالعربي 6.8.10 — مركز تداول مختصر ومجمّع

هذا تحديث **فوق 6.8.9**، ويحافظ على إصلاح شريط الأسعار السفلي وتغييرات Hover والثيمين كما هي.

## طريقة التركيب
- استبدل `index.html` بملف الحزمة.
- أضف `trading-center-compact.css` و`trading-center-compact.js` إلى **جذر المستودع**.
- لا تغيّر أي ملفات أخرى.

## النتيجة
- أصبحت اختصارات مركز التداول الـ13 موزعة على 4 مجموعات قابلة للفتح: الأسواق والأخبار، المختبرات الذكية، إدارة التداول، التعليم والمتابعة.
- جميع الروابط الأصلية محفوظة **دون تعديل وجهاتها**.
- لا تغيير في قسم «المزيد»، شريط أسعار Market Watch، أو شريط أدوات المتداول فوق المركز.
- يعمل على الموبايل بعمودين وعلى اللابتوب بأربعة أعمدة.
- إن أضيفت روابط جديدة لاحقًا تظهر تلقائيًا في مجموعة «أدوات إضافية» بدل فقدانها.
- إذا واجهت أي مشكلة: أعد ملف `index.html` من 6.8.9 واحذف الملفين الجديدين.

هذه طبقة عرض فقط، لا تتعامل مع الأسعار أو التوصيات أو بيانات حسابات المتداول.
