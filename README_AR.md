# ICT بالعربي 6.4 — تحليلات الجمهور والمحتوى

## مبدأ أساسي
ملفات GitHub Pages **لا تجمع إحصاءات جمهور حقيقية وحدها**. لا توجد أرقام مشاهدات/زوار داخل ملفات JSON. قسم المحتوى الموجود في الصفحة الجديدة يقرأ عدد المنشورات وتصنيفاتها فقط. أما الزوار والصفحات الأكثر زيارة فلا يظهرون إلا في لوحة مزود قياس خارجي بعد ربطه.

## الملفات والمجلدات
- استبدل ملفات `index.html`, `app.js`, `platform.css`, `sw.js`.
- استبدل HTML فقط للصفحات: `assets.html`, `workspace.html`, `intelligence.html`, `research.html`, `smart-desk.html`, `workflow.html`, `trust.html` ومجلد `assets/` (صفحات HTML الخمس عشرة). هذه إضافة سكربتات تتبع اختيارية فقط، ولا تُعدل JavaScript الوظيفي لتلك الأدوات.
- أضف: `analytics.html`, `analytics.css`, `analytics-dashboard.js`, `analytics.js`, `analytics-config.js`.
- لا تغيّر ملفات JSON أو سجل المستخدم أو `asset.js` أو `workflow.js` أو لوحة الإدارة أو OneSignal.

## كيفية الاستخدام الفوري
1. ارفع الملفات إلى جذر مستودع GitHub، ومجلد `assets/` إلى مكانه المعتاد.
2. افتح `/analytics.html` وسترى عدد التوصيات والتحليلات والأخبار وتوزيعها حسب الأصل والحالة أو التصنيف.
3. تبقى إحصاءات الزيارات الحقيقية `—` إلى أن تفعّل مزود قياس. وهذا صحيح ومقصود.

## تفعيل Plausible — اختياري
1. أنشئ حساب Plausible وأضف نطاق `ismaeilmoh.github.io` أو النطاق الذي حدده مزود الخدمة. الخدمة خارجية وقد تتطلب اشتراكًا.
2. انسخ رابط ملف السكربت المخصص لموقعك من **Settings → General → Site installation**، شكله `https://plausible.io/js/pa-XXXXX.js`. لا تستخدم مثالًا وهميًا.
3. في `analytics-config.js` اجعل `enabled: true`، وضع الرابط في `scriptUrl` وحدد `siteDomain` المطابق. **لا تضع أي مفتاح API أو كلمة مرور** في الملف.
4. النوافذ تطلب إذن الزائر **قبل** تحميل خدمة الإحصاءات. رفض الزائر لا يمنع الموقع من العمل.
5. أضف أهداف Plausible التالية في إعدادات Goals: `Asset Open`, `Tool Open`, `Section Open`، إذا رغبت بإحصاء نوع الروابط التي يفتحها الزائر. ستعرضها لوحة Plausible بعد استلام أحداث حقيقية.
6. لا تضع الصفحة `admin.html` في التتبع. أيضًا لا تُتبع بيانات السجل والصفقات والقيم المدخلة في النماذج، وإنما روابط التنقل العامة فقط.
7. افتح لوحة Plausible بنفسك لرؤية الأرقام الفعلية؛ صفحة `analytics.html` لا تتصل بمفتاح إحصائي خاص، ولا يمكنها قراءة لوحة حسابك مباشرة.

## الخصوصية
- لا يتم تحميل شيفرة Plausible أو إرسال أي بيانات حتى يتم التفعيل في `analytics-config.js` ويوافق الزائر.
- لا ترسل حقول `ENTRY`, `SL`, `TP`, `R`, حسابات المستخدمين، سجلات Trader DNA، أو مفاتيح GitHub.
- يتم حفظ قرار الموافقة/الرفض محليًا فقط في `localStorage`، ويمكن محوه في صفحة التحليلات.
- **ملاحظة:** تحميل الشارتات أو المصادر الخارجية مثل TradingView وOneSignal مستقل عن هذا التحديث، ولم نغير إعداداتها.

## فحص الإصدار
1. تأكد أن الصفحة العامة تعمل دون موافقة على التتبع.
2. تأكد أن صفحة `/analytics.html` تعرض بيانات المحتوى إذا كانت ملفات JSON متاحة، وتُظهر «غير متاح» عند انقطاعها.
3. عند `enabled: false` لن تُطلب أي ملفات من plausible.io.
4. اختبر بعد تفعيل الخدمة ظهور نافذة الاختيار ثم أحداث الزيارات داخل حسابك.
5. جرّب بعد الرفع `Ctrl + Shift + R` لتجاوز التخزين المؤقت.

## ملاحظات
اختبار JavaScript وZIP لا يغني عن اختبار نشر فعلي في GitHub Pages. قياس الزوار يعتمد على خدمة Plausible وتوافق إعداداتها، ولا يُفترض نجاح جمع زيارات فعلية قبل اختبارها.
