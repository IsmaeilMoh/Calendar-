# ICT بالعربي — تحديث الإشعارات 6.8 جاهز للرفع

**لا تحتاج إلى تعديل أي HTML أو كتابة أي سطر كود.**

## التركيب
1. فك الضغط.
2. افتح مستودع GitHub الخاص بموقعك، وتوجه إلى الجذر (نفس المجلد الموجود فيه `index.html`).
3. ارفع الملفات الخمسة الموجودة داخل الحزمة مباشرة، وليس المجلد الحاوي لها:
   - `index.html` (استبدال)
   - `notify-luxury.css` (إضافة)
   - `notify-luxury.js` (إضافة)
   - `home-polish.css` (تحديث أو استبدال عند الحاجة)
   - `home-polish.js` (تحديث أو استبدال عند الحاجة)
4. اختر Commit changes، ثم بعد النشر افتح الموقع وأعد التحميل باستخدام Ctrl+Shift+R.

## ما الذي تغير؟
- ربط تصميم Quiet Luxury لقسم «خليك أول من يعرف»؛ بقية الموقع بقيت كما هي.
- الاحتفاظ بربط البوكس الرابع (Trader DNA) في غرفة العمليات.
- جميع عناصر الاشتراك والتفضيلات ومعرّفاتها ظلت كما هي، دون أي تغيير في `app.js` أو `push.js` أو OneSignal.

## ملاحظة
ملف `index.html` مأخوذ من حزمة الإصدار 6.8 المبنية على 6.7 وتم فحص الروابط الجديدة. إذا عدّلت `index.html` يدويًا **بعد** تلك النسخة، احتفظ بنسخة احتياطية أولًا لأن الاستبدال سيزيل تعديلاتك الأحدث.

## اختبار سريع
الرئيسية ← بطاقة «خليك أول من يعرف» ← تجربة الاشتراك والتفضيلات. ثم تأكد من ظهور بوكس Trader DNA الرابع في غرفة العمليات.
