# ICT بالعربي 6.8.14 — طبقة لون الأخبار 70%

تحديث صغير مبني على 6.8.13.

- أصبح لون الثيم في التدرج فوق صور «أبرز الأخبار الاقتصادية» بقوة 70% في الداكن والسكري، بدل 60–64%.
- تبقى الصورة الأصلية ظاهرة تحت التدرج، مع المحافظة على تباين النصوص.
- لم يتم تغيير تذييل الموقع، أو شريط Market Watch السفلي، أو Hover، أو مركز التداول، أو أي ملفات JavaScript.
