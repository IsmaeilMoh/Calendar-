# ICT بالعربي — 6.8.13 | توازن ظهور صور الأخبار

هذا تحديث صغير فوق **6.8.12** ولا يغيّر التصميم العام أو منطق التطبيق.

## ما الذي تغير؟
- إزالة تعتيم الصورة المباشر (`opacity: .16` و`.24`) وإعادة وضوح الصورة الأصلية.
- جعل التدرج الذي يغطي الصورة من لون الثيم بنسبة نحو **60%** (مع 64% عند بداية التدرج لدعم قراءة النص).
- الحفاظ على الداكن البترولي والسكري العاجي وعلى تذييل الموقع وشريط Market Watch.

## الرفع إلى GitHub
1. ارفع `theme-surfaces.css` إلى جذر المستودع واستبدل القديم.
2. ارفع `index.html` واستبدل القديم لتحديث رقم كاش CSS إلى `6.8.13`.
3. اترك كل الملفات الأخرى كما هي.

إذا كانت صورة معينة فاتحة جدًا أو مزدحمة، فقد تحتاج لاحقًا إلى تعتيم خاص لتلك الصورة؛ لم تُغير هذه الحزمة محتوى الأخبار أو روابطها.
