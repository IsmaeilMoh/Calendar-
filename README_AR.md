# ICT بالعربي 6.8.15 — تحديث الأيقونات وتوحيدها

هذا التحديث مخصص لتحسين **أيقونات الواجهة** وتوحيدها في الصفحة الرئيسية وباقي الأقسام، مع إضافة أيقونات PWA أحدث.

## ما الذي تم تحسينه؟
- استبدال الرموز القديمة/المتفاوتة بأيقونات SVG حديثة وموحدة.
- توحيد أيقونات:
  - القائمة الرئيسية.
  - شريط التنقل السفلي على الموبايل.
  - شريط «أدوات المتداول» بين الصفحات.
  - تبويبات الصفحات الداخلية (مساحتي / ذكاء الأسواق / مختبر الأبحاث / غرفة المتداول).
  - مجموعات «مركز التداول» في الصفحة الرئيسية.
- إضافة **أيقونات تطبيق موبايل** أحدث (`icon-192.png` و `icon-512.png`).
- الحفاظ على روح الثيمين الحاليين الداكن والسكري من خلال ألوان متوافقة مع الثيم.

## الملفات المضافة/المستبدلة
- `index.html`
- `workspace.html`
- `intelligence.html`
- `research.html`
- `smart-desk.html`
- `ui-icons.css`  ← ملف جديد
- `ui-icons.js`   ← ملف جديد
- `icon-192.png`
- `icon-512.png`

## طريقة التركيب
1. افتح مستودع GitHub الخاص بالموقع.
2. ارفع الملفات المذكورة أعلاه إلى جذر المشروع.
3. وافق على **استبدال** الملفات القديمة عند الطلب.
4. تأكد أن الملفين الجديدين `ui-icons.css` و `ui-icons.js` تم رفعهما فعلًا.
5. انتظر تحديث GitHub Pages ثم حدّث الموقع تحديثًا قويًا (Ctrl+F5).

## ملاحظة
إذا كانت نسخة قديمة من الأيقونات ما زالت تظهر على الهاتف، جرّب:
- حذف اختصار التطبيق ثم إعادة تثبيته.
- أو مسح Cache المتصفح / Service Worker ثم إعادة فتح الموقع.
