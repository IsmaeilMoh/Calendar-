# ICT بالعربي 5.6 — شاشة افتتاح التطبيق المتحركة

هذا تحديث فوق النسخة 5.5 بعد موافقتك على معاينة حركة الشعار، ولا يغير محتوى الموقع أو تصميم الشعار.

## ارفع إلى جذر GitHub
**استبدل** `index.html`، `sw.js`، `manifest.json`.
**أضف** `splash.css`، `splash.js`.
**لا تستبدل** `logo-original.jpeg` الموجود لديك؛ أضفت نسخة مطابقة لملف الشعار الأصلي المعتمد لأغراض المعاينة والتأكد فقط. إذا كان عندك نفس الملف فلا حاجة إلى رفعه.

## كيف تعمل الحركة؟
- تظهر تلقائيًا عند تشغيل الـPWA المثبت بنمط `standalone` على الصفحة الرئيسية؛ ولا تظهر في متصفح الموقع العادي أو عند التنقل بين الصفحات.
- معاينة اختيارية على أي متصفح: `https://ismaeilmoh.github.io/ictbelaraby/?splash=1`.
- لتعطيلها مؤقتًا في التطبيق لأغراض التصحيح: `?splash=0`.
- يظهر الشعار الأصلي تدريجيًا مع حلقتين خافتتين وشريط تحميل مرئي ثم تختفي الشاشة خلال نحو 3 ثوانٍ.
- لا تتوقف على تحميل TradingView أو بيانات السوق. تحترم خيار تقليل الحركة في نظام الهاتف.
- لا يوجد تسجيل أو تجميع بيانات أو شبكات خارجية إضافية للحركة.

## تنبيه مهم عن أندرويد
أندرويد يعرض شاشة إطلاق أصلية قبل تشغيل كود صفحة الويب. هذه الشاشة قد تظهر أيقونة الموقع داخل قناع مربع أو دائرة حسب الهاتف وإصدار أندرويد. **الـCSS/JS لا يستطيع تغيير شكل هذه الشاشة الأصلية أو إضافة حركة إليها**. ضبطنا `background_color` في ملف Manifest إلى الأبيض لتكون مرحلة الانتقال البصرية متناسقة، لكن شكل الأيقونة الأصلية قد يبقى كما هو. تغيير تلك الأيقونة يتطلب تصميم أيقونات PWA ملائمة أو تطبيق أندرويد أصلي/TWA.

## تحقق بعد الرفع
1. احفظ نسخة احتياطية من `index.html`, `manifest.json`, `sw.js`.
2. ارفع الملفات الخمسة المذكورة في جذر المستودع، واعمل Commit وانتظر نشر GitHub Pages.
3. افتح رابط المعاينة بـ `?splash=1` على الموبايل لترى الحركة.
4. افتح تطبيق PWA المثبت من أيقونته. قد يتطلب تحديث الـPWA إغلاقه وفتحه مرة أخرى؛ وإذا بقيت النسخة القديمة، حدّث الموقع من المتصفح أولًا.
5. تأكد أن بعد الحركة تظهر الصفحة الرئيسية وتعمل الأخبار والتوصيات والإشعارات والأقسام الأخرى.

## لم ألمس
`app.js`, `style.css`, `typography.css`, `platform.js`, `platform.css`, ملفات JSON، `push.js`, `push-config.js`, إعدادات OneSignal، ملفات الإدارة أو أدوات المراحل السابقة.
