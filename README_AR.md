# ICT بالعربي 4.3 — Economic Brief + ICT Window

## الجديد
- عرض «الخبر الاقتصادي القوي القادم» و«نافذة ICT الحالية» داخل بطاقتين متجاورتين على شاشات اللابتوب المناسبة.
- ترتيب تفاصيل كل بطاقة عموديًا من الأعلى للأسفل مع تكبير الخط للعناوين والعد التنازلي واسم جلسة ICT.
- الحفاظ على التفاصيل القابلة للتوسيع والمواعيد الدقيقة.
- العرض المتجاوب: عندما تضيق مساحة لوحة Market Pulse (نحو 420px أو أقل)، تصبح البطاقتان فوق بعض تلقائيًا، حتى لا تُقصّ النصوص.
- لم تتغير الأسعار أو مصدر TradingView أو إدارة الأخبار والتنبيهات.

## التركيب
1. افتح المستودع: https://github.com/IsmaeilMoh/ictbelaraby
2. استبدل في جذر المشروع **فقط**: `app.js` و`style.css` و`sw.js`.
3. اضغط Commit changes.
4. افتح الموقع بعد نشر GitHub Pages وحدّث الصفحة باستخدام `Ctrl + F5`.

**تنبيه:** لا تستبدل ملفات JSON أو مجلدات الصور أو `push-config.js` أو أي Workflow. لا يوجد تعديل على هذه الملفات.

## التحقق
- تأكد أن البطاقتين متجاورتان على اللابتوب، ونص الخبر والعد التنازلي واسم الجلسة واضح.
- على الهاتف، يجب أن تتكدس البطاقتان رأسيًا.
- جرب فتح تفاصيل الخبر ومواعيد نافذة ICT وتأكد من بقاء الأوقات والتوقيتات صحيحة.
