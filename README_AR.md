# ICT بالعربي 6.8.22 — Logo & Name Glass Badge

تحديث تنسيقي محدود **مبني على 6.8.21**.

## ما تغير؟
- إزالة العبارة الإنجليزية تحت اسم الموقع في شريط الهيدر.
- أصبح البوكس يحتوي على **الشعار الأصلي + ICT بالعربي** فقط.
- ضبط عرض البوكس بقدر محتواه على الهاتف واللابتوب، دون مساحة زائدة.
- الحفاظ على الزجاجية واللمعة والحركة الأصلية عند Hover.
- توحيد شكل علامة الموقع في صفحات الرئيسية ومساحة المتداول وذكاء الأسواق ومختبر الأبحاث وغرفة المتداول.
- إبقاء كل وظائف الموقع، وشريط الأسعار، وزر تغيير الثيم، وحالات Hover الأخرى بدون تغيير.

## الرفع على GitHub

لا تغيّر `app.js` أو ملفات الثيم أو الإشعارات.
