# ICT بالعربي 5.4 — Platform Unification & Quality Pass

## الغرض
هذه حزمة **تحديث تكاملي محدودة** فوق الإصدار 5.3. توحد تجربة الانتقال بين صفحات المشروع وتحسن تحديث النسخ المخزنة، دون لمس البيانات أو أنظمة النشر والأسعار والإشعارات.

## ما يتغير
- شريط أدوات موحد في الصفحات: الرئيسية، مساحتي، ذكاء الأسواق، مختبر الأبحاث، غرفة المتداول، التوصيات، الأجندة.
- روابط انتقال أصلية ضمن موقع GitHub Pages، مع إظهار الصفحة النشطة وحالة اتصال الجهاز.
- تصميم فحمي زجاجي متجاوب خاص بالشريط الموحد دون استبدال تصاميم الصفحات.
- روابط محسنة لاستخدام لوحة المفاتيح والتركيز الواضح، ودعم `prefers-reduced-motion`.
- إعادة بناء Service Worker لتقليل خطر عدم تثبيت تحديث عندما يتعذر تحميل ملف اختياري.
- تقديم ملفات HTML/CSS/JS من الشبكة أولًا عندما تكون متاحة، مع استعمال النسخ المحلية عند انقطاعها.
- عدم تقديم بيانات السوق والأجندة الحية من ذاكرة قديمة باعتبارها بيانات حديثة.
- منع حذف كاش مواقع GitHub Pages الأخرى: يتم حذف الكاش الذي يبدأ بـ `ict-shell-` فقط.
- حفظ إصدار جديد في روابط CSS/JS لمساعدة المتصفح على تحديثها.

## خطوات آمنة
1. من GitHub نزّل ZIP للمستودع الحالي لعمل نسخة احتياطية، واحفظ كذلك نسخة من بياناتك الشخصية التي في متصفحك (Trader DNA، نماذج Research Lab وغيرها).
2. افتح GitHub → مستودع `IsmaeilMoh/ictbelaraby`.
3. ارفع الملفات الثمانية المذكورة إلى **جذر المستودع** فقط، واستبدل النسخ السابقة عند مطالبتك بذلك.
4. اعمل Commit.
5. افتح GitHub Actions/Pages وتأكد من اكتمال النشر.
6. افتح الموقع في نافذة خاصة للتحقق من شريط التنقل، ثم جرّب Ctrl+Shift+R في نافذتك الأصلية.
7. تنقل بين صفحات الأدوات الخمس، وجرّب التوصيات والأجندة وزر الاشتراك بالإشعارات.
8. لا تحذف أي بيانات منشورة لغرض الاختبار؛ اكتف بمراجعة وظائف القراءة والتنقل.

## تنبيه أمني
GitHub Pages منصة استضافة ثابتة. إخفاء `admin.html` من قوائم الجمهور لا يعد حماية أمنية؛ الحماية من تعديل محتوى GitHub تعتمد على صلاحية Personal Access Token. لا تضع رموز GitHub أو مفاتيح REST API في JS أو HTML، ولا تنشرها في المستودع.

## حدود الإصدار
- هذا **توحيد واجهة وتنقل وطبقة تخزين مؤقت** وليس نقلًا إلى خادم خلفي أو نظام حسابات للمستخدمين.
- لم تتغير حقوق العرض أو حداثة أسعار TradingView؛ ولا أصبحت بيانات الرادار لحظية.
- لم تتحقق اختبارات متصفح محلية كاملة؛ البيئة تمنع فتح عنوان HTTP المحلي داخل Chromium. تمت فحوص الملفات وصياغة JavaScript والروابط الثابتة.
- لا يمكن الجزم بأن الوضع في الموقع المنشور مطابق للحزمة قبل رفعها وتجربتها.
