# ICT بالعربي 6.7 — البوكس الرابع وتصغير بطاقة الإشعارات

## ماذا يتغير؟
- بوكس رابع في غرفة عمليات التداول بعنوان «بصمة أدائك»، يفتح `smart-desk.html` لتحليل سجل الصفقات.
- تصغير قسم «خليك أول من يعرف»، بما في ذلك الجرس والحشوات وزر الاشتراك، دون تغيير الأكواد التي تشترك في الإشعارات أو تفضيلاتها.
- التغييرات تخص الرئيسية فقط.

## التثبيت
1. احتفظ بنسخة من `index.html` الحالي في GitHub.
2. ارفع `home-polish.css` و`home-polish.js` إلى جذر المستودع.
3. استبدل `index.html` بالنسخة في الحزمة **فقط إذا كان الملف الحالي مطابقًا لنسخة 5.5/6.6 المنشورة التي استخدمناها أساسًا**. إذا عدّلته بعد ذلك، أضف السطرين أدناه بدل استبدال الملف:
   - داخل `<head>` قبل `</head>`: `<link rel="stylesheet" href="home-polish.css?v=6.7.0">`
   - قبل `</body>` بعد تحميل `app.js`: `<script src="home-polish.js?v=6.7.0" defer></script>`
4. Commit changes ثم Ctrl+Shift+R. إذا كان تطبيق PWA يحتفظ بالكاش أغلقه وأعد فتحه.

## حماية الملفات
لا تستبدل `app.js` أو `style.css` أو `platform.css` أو `sw.js` أو أي ملفات JSON أو إعدادات OneSignal أو ملفات الإدارة.
لا توجد أي بيانات تداول مصطنعة في البوكس الجديد؛ هو مدخل لميزة موجودة.

## التحقق
- على لابتوب أعرض من 1120px يجب ظهور أربعة صناديق متجاورة.
- في عرض 760–1120px تظهر غالبًا بطاقتان في كل صف، وفي الهاتف عمود واحد، وفق CSS الحالي.
- زر تفعيل الإشعارات وتخصيصها يحتفظان بنفس المعرفات وسلوكهما القديم.
