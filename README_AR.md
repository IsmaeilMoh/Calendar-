# ICT بالعربي 5.3 — المرحلة الرابعة: Smart Trader Desk

**يُثبَّت فوق الإصدار 5.2** بعد رفعه إلى GitHub Pages.

## ما الجديد؟

1. **Trader DNA:** سجل صفقات شخصي بوحدة `R`، مع حساب العدد، نسبة الصفقات الرابحة، صافي `R`، التراجع الأقصى من منحنى R التراكمي، وتجميع الأداء حسب الأصل والجلسة والاستراتيجية. إضافة وحذف وتصدير CSV ونسخة JSON احتياطية واستيرادها.
2. **مساعد البحث في محتوى ICT بالعربي:** بحث من داخل ملفات `analyses.json` و`recs.json` و`news-live.json` و`calendar-live.json`، مع روابط للمصادر. **ليس نموذج ذكاء اصطناعي توليديًا**؛ لا يخترع توقعات أو يتصل بخدمة AI مدفوعة.
3. **ICT Live Desk:** آخر التحليلات والتوصيات، الأخبار الحديثة، الأحداث القادمة، ولقطة حركة الأصول، مع عرض وقت تحديث مصادر البيانات. تحديث يدوي أو أثناء فتح الصفحة كل خمس دقائق. هذه **ليست بث أسعار tick-by-tick**.

**استبدل:**

`https://ismaeilmoh.github.io/ictbelaraby/smart-desk.html`

ستجد رابط «غرفة المتداول الذكية» في مركز التداول بالرئيسية وفي صفحة «المزيد».

## تنبيهات مهمة

- لا ترفع ملفات JSON من هذه الحزمة؛ **الحزمة لا تحتوي عليها**. اترك ملفات `news-live.json` و`calendar-live.json` و`market-movers.json` و`recs.json` و`analyses.json` كما هي.
- لا تغيّر ملفات `admin.*`، أو إعدادات OneSignal، أو `.github` أو `scripts` أو صفحات workspace/intelligence/research السابقة.
- يحفظ سجل Trader DNA داخل متصفح الزائر باستخدام `localStorage`، ولا يتزامن مع الأجهزة الأخرى. يستحسن تصدير نسخة JSON احتياطية.
- الحسابات تفترض إدخال نتائج الصفقة بوحدة R بعد تكاليفها إن رغبت. وهي **إحصاءات وصفية فقط**، لا تنبؤات بفرص قادمة.
- القيم الاقتصادية والأسعار هي نفس ما تنتجه ملفات الموقع الحالية؛ قد تتأخر ولا تستخدم تلقائيًا لتوليد إشارات شراء أو بيع.
- فتح الصفحة من `file://` قد يمنع جلب ملفات JSON؛ اختبرها بعد نشرها على GitHub Pages.
- إن بقي التصميم القديم، جرّب `Ctrl + Shift + R` بعد تحديث GitHub Pages.

## اختبارات سريعة

1. افتح «غرفة المتداول الذكية» وتأكد من ظهور تبويبات Live Desk وTrader DNA والمساعد البحثي.
2. سجّل صفقة بـ `-1 R` وأخرى بـ `+2 R`؛ يجب أن يظهر العدد `2` وصافي `+1 R` ونسبة ربح 50%.
3. صدّر نسخة JSON واستوردها بعد التحقق من محتواها؛ الاستيراد **يستبدل** السجل المحلي بعد التأكيد.
4. ابحث عن `XAUUSD` أو «آخر التوصيات»، وتأكد أن النتائج ترتبط بالمحتوى المنشور.
5. راجع توقيت آخر تحديث للأجندة والأسعار. قد تظهر رسالة عدم توفر إذا كان الملف غير متاح، بدل أرقام وهمية.

## حدود الإصدار

لا توجد مصادقة مستخدمين أو سحابة شخصية، ولا مساعد AI توليدي، ولا بث لحظي مستقل، ولا ربط ببيانات حساب الوسيط. يمكن بناء هذه القدرات لاحقًا بتصميم خدمة خلفية آمنة ومراعاة خصوصية المستخدم وترخيص بيانات الأسواق.
