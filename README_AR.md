# ICT بالعربي 6.8 — إصلاح تشغيل شاشة الافتتاح

## السبب الذي تم التحقق منه
حزمة التعديل السابقة لم تتضمن ملف `index.html` جاهزًا؛ احتوت على ملف تعليمات `index_snippet.html`، وهو لا يُشغّل الحركة بمجرد رفعه. فحصت `index.html` الأصلي داخل `ICT_Arabic_6.8_READY_TO_UPLOAD.zip` ووجدته دون أي استدعاء لشاشة الافتتاح.

## التركيب
1. افتح جذر مستودع موقع ICT بالعربي على GitHub.
2. ارفع هذه الملفات **الأربعة** إلى الجذر مباشرة (لا ترفع المجلد الخارجي):
   - `index.html` — **استبدال**، وهو مبني على 6.8 ويحافظ على `home-polish` و`notify-luxury`.
   - `splash.css` — إضافة/استبدال.
   - `splash.js` — إضافة/استبدال.
   - `splash-logo-transparent.png` — إضافة.
3. اضغط **Commit changes** ثم انتظر اكتمال GitHub Pages.
4. افتح من المتصفح: `https://ismaeilmoh.github.io/ictbelaraby/?splash=1` للتأكد من عمل الأنيميشن.
5. بعد ذلك افتح التطبيق المثبت من أيقونته. إن ظهرت النسخة القديمة، أغلق التطبيق كليًا وفتحه من جديد. وقد يتطلب تحديث Service Worker وقتًا أو إزالة التطبيق وإعادة تثبيته إذا بقيت نسخة قديمة في التخزين.

## ملاحظات
- الحركة تظهر تلقائيًا في وضع تطبيق PWA المثبت، وتظهر في المتصفح فقط عند استخدام `?splash=1`.
- خط التحميل متباعد عن الشعار ويتحرك من اليمين إلى اليسار.
- لم تُمس صورة الشعار الأصلي `logo-original.jpeg` ولا ملفات الأخبار أو لوحة الإدارة أو OneSignal أو البيانات.
- شاشة أندرويد النظامية التي تسبق تحميل الموقع لا يمكن تحريكها بـCSS.
- إذا عدّلت `index.html` بعد إصدار 6.8 بنفسك، قارن الفرق قبل الاستبدال.
