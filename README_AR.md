# ICT بالعربي 6.8.25 — Premium Compact Header

هذا تحديث تجميلي متدرّج فوق 6.8.24، دون استبدال أي منطق تداول أو إدارة أو إشعارات.

- تخفيف ارتفاع الهيدر ومسافاته مع الحفاظ على قراءة اسم الموقع وشعاره الأصلي.
- موازنة بوكس الهوية الزجاجي مع زر تبديل الثيم.
- تحسين خلفية الهيدر والإطار والظل في الوضعين الفحمي والسكري.
- إنشاء مجموعة زجاجية رقيقة لروابط القائمة على اللابتوب، مع Hover مطابق لألوان الثيم.
- على الموبايل يبقى التنقل الحالي كما هو، والهيدر مضغوط في صف واحد قدر الإمكان.
- الحفاظ على لمعان Hover حول بوكس الشعار وزر الثيم، وعلى الشريط السفلي Market Watch دون تغيير.

## طريقة الرفع
ارفع فقط `index.html` و `ui-icons.css` إلى جذر المستودع، واستبدل الملفين السابقين.
باقي الملفات كما هي من 6.8.24 والإصدارات السابقة.
