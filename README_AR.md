# ICT بالعربي 6.1.1 — إصلاح الثيم الداكن لغرفة عمليات الصفحة الرئيسية

## السبب
الموقع يستخدم `data-theme="dark"` على عنصر `<html>`، بينما قواعد غرفة العمليات كانت تعتمد على `html.dark` غير الموجود. لهذا بقيت خلفية غرفة العمليات وبطاقاتها فاتحة.

## الإصلاح
- مطابقة ثيم غرفة العمليات مع `[data-theme="dark"]` الذي يستخدمه الموقع بالفعل.
- ضبط ألوان النصوص كي تستخدم متغير `--ink` المعرّف في هوية الموقع.
- تحديث رقم الاستدعاء لملف CSS في الصفحة إلى 6.1.1 لتفادي عرض النسخة المخزنة.
- الحفاظ على العرض الفاتح كما هو وعلى وظائف غرفة العمليات وMarket Pulse والشريط الموحد.

## التركيب
استبدل ملفين فقط في جذر مستودع GitHub:
1. `platform.css`
2. `index.html`

ثم Commit changes، وأعد تحميل الصفحة بـ Ctrl + Shift + R وجرب الزر «المظهر» بين فاتح وداكن وتلقائي.

**لا تستبدل `app.js` أو `sw.js`، ولا ملفات الأسعار أو الأخبار أو الإدارة أو OneSignal.**
