## التنفيذ
1. شريط «أدوات المتداول» انتقل إلى **فوق عنوان مركز التداول** في الرئيسية، مع المحافظة على جميع الروابط. عند الانتقال إلى صفحة أخرى داخل الرئيسية يعود مؤقتًا تحت الهيدر (لأن مركز التداول لا يكون ظاهرًا)، ثم يعود مكانه عند الرجوع للرئيسية.
2. تصغير مربعات مركز التداول: خمسة أعمدة في الشاشات الواسعة، أربعة في المتوسطة، اثنان في الموبايل، وتقليل المسافات والارتفاع.
3. توحيد خط Almarai في الواجهات الخمس، مع Inter للأرقام والمصطلحات المالية ذات اتجاه LTR.
4. تعديل ألوان Market Pulse والتوصيات والأجندة والأخبار واللوحات المختبرية كي ترث الثيم الفحمي/البترولي أو السكري/العاجي.
5. الإبقاء على شريط أسعار السوق **الثابت أسفل الشاشة (`.tape`) داكنًا في كلا الثيمين فقط**؛ لا يشمل ذلك شريط التنقل السفلي للموبايل.

## مهم
- هذا CSS يحسّن الواجهات، ولا يمس `app.js` أو `platform.js` أو `platform.css` أو ملفات الإشعارات أو JSON.
- صفحات أخرى مستقلة مثل `workflow.html` و`assets.html` و`agenda.html` و`admin.html` **ليست داخل الحزمة** لعدم امتلاك نسخة أصلية حديثة مؤكدة منها. لا نستبدلها بنسخ قديمة. عند الرغبة في توحيدها يلزم جلب نسخها الحالية من GitHub ثم إلحاق نفس التصميم بها.
- بعض الأدوات المضمّنة كـ TradingView iframe تتحكم بألوانها عبر إعداداتها الخاصة، ولا يستطيع CSS للموقع تغيير محتوى الإطار الخارجي.
- اختبر سلوك التغيير بين الثيمين والتصفح إلى `#recs` ثم العودة إلى `#home`، وأن أدوات المتداول تظهر فوق مركز التداول فقط بالرئيسية.
- إن ظهر خلل، تراجع عن السبعة ملفات للتحديث السابق (احذف ملفي design-consistency وأعد ملفات HTML الخمسة من 6.8.5).
