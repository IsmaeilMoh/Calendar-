# ICT بالعربي 6.8.4 — Bento × Glass Refinement

**الأساس المعتمد:** `ICT_Arabic_6.8.3_UNIFIED_THEMES_READY_TO_UPLOAD.zip` (المبني على 6.8 الأصلي). هذه حزمة تحديث مرئية وليست إعادة تصميم 7.0.

## ما الجديد؟
- الحفاظ على ألوان وتدرجات **الفحمي/البترولي** و**السكري/العاجي** نفسها من 6.8.3.
- لمسة Glassmorphism محسوبة: تدرج زجاجي خفيف وحد رقيق وظل داخلي للبطاقات.
- إحساس Bento Grid عبر زوايا متناسقة وتمايز البطاقات الموجودة **دون تغيير شبكة الأعمدة أو ترتيب المحتوى**.
- تنقل أكثر نعومة وحواف متسقة وحالات تركيز واضحة.
- تقليل تأثيرات الضبابية على الموبايل والأجهزة محدودة الأداء.

## تعليمات الرفع
1. احتفظ بنسخة احتياطية من مستودعك الحالي.
2. فك الضغط وارفع محتويات ZIP إلى **جذر المستودع** (لا ترفع المجلد الحاوي).
3. **استبدل** `index.html`, `workspace.html`, `intelligence.html`, `research.html`, `smart-desk.html` بملفات الحزمة إذا كانت مطابقة لما على موقعك من إصدار 6.8.3. **أضف** `bento-glass.css`.
4. الملفات `unified-theme.css` و`unified-theme.js` وملفات Home Polish وQuiet Luxury مضمنة دون أي تعديل في هذه الحزمة؛ لا حاجة لاستبدالها إذا هي موجودة.
5. اضغط Commit changes وانتظر تحديث GitHub Pages، ثم جرّب `Ctrl+Shift+R`.

## نطاق التحديث وحماية البيانات
- لم يتم تعديل ملفات JavaScript أو ملفات JSON أو OneSignal أو إعدادات PWA أو Service Worker أو الشعار.
- لا توجد شاشة افتتاح/أنيميشن مضافة.
- تحديث هذه الحزمة يشمل الصفحات العامة الخمس فقط؛ **لوحة الإدارة وصفحة الأجندة المستقلة خارج النطاق**.
- تحديث 6.8.3 استند في صفحات الأدوات إلى ملفات واجهات سابقة. إن عدلت هذه الصفحات مؤخرًا، لا ترفعها بشكل أعمى: يمكن إضافة رابط `bento-glass.css?v=6.8.4` بعد `unified-theme.css` إلى كل صفحة موجودة لديك مع رفع CSS الجديد فقط.

## اختبار سريع
- جرّب الرئيسية، مساحتي، ذكاء الأسواق، مختبر الأبحاث، غرفة المتداول في الوضعين الداكن والفاتح.
- تحقق من حقول الإدخال والتبويبات والقوائم المنسدلة ووضوح الأرقام.
- تحقق أن البطاقات متراصة دون تمدد أو تمرير أفقي على شاشة 390px.
- افحص التوصيات والإشعارات والبيانات والتحويل بين الصفحات.
