# ICT بالعربي 6.8.23 — الشعار والوصف داخل بوكس واحد

مبني على 6.8.22، مع الإبقاء على بقية التحديثات السابقة.

- إزالة الشريط العلوي الذي يعرض اسم الموقع والتاريخ والوقت.
- عرض «مساحة المتداول العربي» تحت «ICT بالعربي» داخل نفس بوكس الشعار الزجاجي.
- الحفاظ على ملف الشعار الأصلي، وHover ولمعة الإطار، وألوان الثيمين.
- الحفاظ على عنصر التاريخ `#today` مخفيًا في DOM لتجنب تعطل أي كود قد يكتب فيه، مع عدم عرضه للمستخدم.
- لا تغيير بملفات التداول أو منطق الثيم.

## الرفع إلى GitHub

استبدل **`index.html`** و**`ui-icons.css`** فقط من هذه الحزمة، في جذر المستودع. بعد النشر حدّث بقوة (Ctrl+F5). لا تحذف الملفات الأخرى من المستودع.
