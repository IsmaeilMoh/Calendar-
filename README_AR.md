# ICT بالعربي — تحديث 3.7 لشريطي الأسعار

## ما الذي تغير؟
- شريط الأكثر صعودًا وهبوطًا: رمز الأصل + **السعر** + سهم ▲/▼ + التغير المئوي.
- الشريط الثابت أسفل الشاشة: نفس العرض بصورة مدمجة للموبايل والكمبيوتر.
- تستخدم الأسعار المنشورة من سكربت GitHub Actions الحالي دون مصادر أو طلبات إضافية من متصفح الزائر.
- لا تظهر أسعار مفترضة: إذا كان ملف السوق القديم لا يحتوي على السعر، تظهر شرطة (—) حتى أول تحديث ناجح.
- الذهب والفضة والنفط تستخدم العقود الآجلة المرجعية الحالية، وليس أسعار spot المباشرة؛ لم نغيّر مصادر الاقتباسات.
- الشريطان يعرضان لقطة دورية، وليسا أسعار بث لحظي.

## طريقة التثبيت
1. فك الضغط، ثم افتح مستودع GitHub `IsmaeilMoh/ictbelaraby`.
2. استبدل الملفات التالية في نفس المسارات تمامًا:
   - `app.js`
   - `style.css`
   - `sw.js`
   - `scripts/update_movers.py` (داخل مجلد scripts؛ لا ترفع الملف إلى الجذر).
3. اعمل Commit changes على فرع `main`.
4. من Actions شغّل مهمة `Update Market Movers` أو `update-movers.yml` بـ `Run workflow` مرة واحدة بعد رفع الملفات. هذه الخطوة أساسية لأنها تولّد `market-movers.json` مع السعر الجديد.
5. تأكد أن المهمة خضراء وملف `market-movers.json` يحتوي على مفتاح `price` داخل عناصر `items`، ثم افتح موقعك وحدّثه تحديثًا كاملًا.
6. إذا لم تتوفر الأسعار من المصدر أثناء التشغيل، لن يزوّر النظام قيمًا؛ سيبقى ملف السوق السابق ظاهرًا حتى ينجح التشغيل التالي.

## ما لا يجب رفعه/استبداله
- لا ترفع ملف `market-movers.json` القديم أو ملفًا فارغًا؛ سكربت GitHub هو المسؤول عن توليده.
- لا تستبدل `recs.json` أو `analyses.json` أو `news-live.json` أو `calendar-live.json`.
- لا تعدّل ملفات `admin.*` أو `push-config.js` أو إعدادات OneSignal أو workflows.

## تدقيق سريع
- تطبيق JavaScript يستعمل `x.price` فقط إذا كان رقمًا موجبًا صالحًا؛ لا يحسب السعر من النسبة.
- القيمة الرقمية تعرض بدقة مناسبة للرمز؛ تمثيلها المعروض مقرب فقط مع بقاء قيمة JSON الأصلية.
- الأسهم تعبر عن التغير نسبةً إلى الإغلاق المرجعي السابق وليست آخر tick.
