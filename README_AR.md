# ICT بالعربي 6.7 — فصل واجهة الزائر عن أدوات المطوّر

## ماذا تغيّر؟
- إلغاء بطاقة **صحة مصادر البيانات** من غرفة عمليات الصفحة الرئيسية.
- إلغاء اختصار **مركز موثوقية البيانات** من مركز التداول.
- إزالة اختصارَي **تحليلات المحتوى والجمهور** المكررين من قسم «المزيد».
- إزالة **موثوقية البيانات** من قائمة «المزيد» الخاصة بالموبايل في الصفحات المستقلة.
- تجميع روابط **فحص موثوقية البيانات** و**تحليلات الجمهور والمحتوى** في لوحة النشر `admin.html` داخل مساحة العمل التي تظهر بعد الاتصال بمستودع GitHub.
- إلغاء التخزين التمهيدي لصفحات التشخيص في الـService Worker، وطلب هذه الصفحات مباشرة دون تخزينها ضمن كاش واجهة الزائر.
- وضع `noindex,nofollow` على صفحة فحص البيانات لمنع الفهرسة العادية (ليس وسيلة حماية من الوصول المباشر).
- **الإبقاء على تحذيرات قدم الأسعار والأخبار والأجندة العامة** التي يحتاجها المتداول؛ فهي ليست إعدادات مطوّر.

## الملفات التي تُستبدل في جذر GitHub
1. `index.html`
2. `app.js`
3. `mobile.js`
4. `sw.js`
5. `admin.html`
6. `trust.html`

لا تغيّر `style.css` أو `admin.js` أو `push.js` أو OneSignal أو JSON أو بيانات المتداول.

## التحقق
- افتح الرئيسية ثم «المزيد»: لن ترى أدوات المطوّر ضمن بطاقات الزوار.
- افتح صفحة أصل على الموبايل، ثم «المزيد»: لن ترى موثوقية البيانات.
- افتح `admin.html` وأدخل صلاحياتك المعتادة: تظهر روابط الأدوات بعد نجاح الاتصال.
- تحقق أن تنبيهات البيانات القديمة في Market Pulse والصفحات العامة ما زالت تعمل.
- إذا ظهر الكاش القديم، حدّث الصفحة بـ Ctrl + Shift + R.

## تنبيه أمني مهم جدًا
هذه **عملية إخفاء للواجهة العامة وتنظيم أدوات الإدارة**، وليست نظام مصادقة للصفحات الإدارية.
على GitHub Pages، لا تزال `trust.html` و`analytics.html` قابلة للوصول لمن يعرف روابطها، ومحتواهما العام قابل للعرض. كما أن جميع ملفات JavaScript المنشورة عامة. الحماية الفعلية تحتاج بوابة مصادقة وتحققًا من الصلاحيات على خادم/استضافة تدعم ذلك، أو نقل الأدوات الخاصة إلى بيئة غير عامة.
لا تضع رموز GitHub أو أسرار API أو معلومات خاصة في ملفات الموقع العامة. حماية نشر المحتوى تعتمد على صلاحيات GitHub Token الحقيقية.
