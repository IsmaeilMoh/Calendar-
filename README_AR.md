# ICT بالعربي 6.1 — Financial Asset Hub

## تحديث الصفحات المستقلة للأصول المالية
النسخة تضيف دليل أصول مستقل (`assets.html`) و15 صفحة أصل (`assets/XAUUSD.html` وغيرها)، مع ملفات العرض المشتركة `asset.js` و`asset.css` و`asset-config.js`.

- الذهب والفضة: XAUUSD وXAGUSD
- الفوركس: EURUSD وGBPUSD وUSDJPY وUSDCHF وUSDCAD وAUDUSD وNZDUSD
- المؤشرات: NAS100 وSP500 وDJ30
- النفط: WTI
- العملات الرقمية: BTCUSD وETHUSD

كل أصل له عنوان URL ثابت داخل مجلد `assets/`. الصفحات تعرض شارت TradingView المدمج، ولقطة سعر مرجعية لا تُعرض إذا انتهت حداثتها، والتحليلات والتوصيات من ملفات الموقع الحالية، والأخبار المطابقة نصيًا والأحداث ذات العملات ذات الصلة. لا تقدّم توقعات تلقائية ولا تدّعي أن الأسعار لحظية.

## طريقة التركيب
1. فك الضغط.
2. في جذر مستودع GitHub، **استبدل**: `index.html`, `app.js`, `platform.js`, `sw.js`.
3. **أضف**: `assets.html`, `asset.css`, `asset.js`, `asset-config.js` ومجلد `assets` بكامل ملفاته (15 صفحة HTML).
4. لا تستبدل `platform.css` أو `style.css` أو `recs.json` أو `analyses.json` أو بيانات الأسعار والأخبار أو أي ملف لإشعارات OneSignal أو لوحة الإدارة.
5. احفظ التغييرات عبر Commit، وبعد نشر GitHub Pages افتح `https://ismaeilmoh.github.io/ictbelaraby/assets.html`.
6. لتجنب نسخة قديمة مخزنة استخدم Ctrl+Shift+R عند الحاجة.

## التحقق والحدود
- البيانات السعرية من `market-movers.json` وهي لقطات دورية قد تتأخر؛ في غياب التوقيت أو إذا تجاوزت ست ساعات يُخفى السعر بدل ادعاء حداثته.
- لا يوجد مفتاح API ولا خادم جديد؛ يفتح شارت TradingView من مصدره الخارجي وقد يتأخر أو يُحجب في بعض الشبكات.
- ترشيح التحليلات والتوصيات يعتمد على مطابقة رموز الأصول، ولا يغيّر الملفات الحالية.
- الأخبار تُرشح بمطابقة أسماء ورموز الأصول؛ الأخبار الاقتصادية العامة قد لا تظهر رغم أهميتها لبعض الأصول.
- الأجندة ترشح حسب العملة المتاحة في المصدر، وليس حسب تقييم تأثير مؤكد على الأصل.
- لا يتم إدخال الأسعار/التوصيات التجريبية ضمن النتائج المنشورة.
