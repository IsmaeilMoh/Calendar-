# ICT بالعربي 4.5 — محتوى وأدوات ولوحة إدارة

يضم هذا الإصدار التطويرات **5 و6 و7 و8 فقط**. قسم انحياز السوق اليومي (4) **لم يُضف**.

## التركيب
استبدل في جذر المستودع الملفات الستة: `app.js`, `style.css`, `sw.js`, `admin.html`, `admin.js`, `admin.css`.
لا تستبدل ملفات الأسعار والبيانات ولا إعداد OneSignal.

## الأقسام الجديدة
1. **قراءة نتائج الأخبار**: `#intelligence` — يقارن الأرقام الفعلية والمتوقعة إن كانت قابلة للمقارنة؛ **لا يتنبأ بالاتجاه** ولا ينشر تحليلًا آليًا للسوق.
2. **أكاديمية ICT**: `#academy` — ثمانية دروس واختبارات قصيرة؛ التقدم محفوظ على الجهاز في localStorage.
3. **حاسبات التداول**: `#calculators` — مخاطرة/حجم لوت نظري وعائد إلى مخاطرة. أدخل قيمة النقطة/البيب للوت الواحد حسب وسيطك، المثال الافتراضي 10 **ليس مناسبًا لجميع الأصول**.
4. **لوحة النشر**: `admin.html` — ملخص إحصائي للمنشورات، تصدير CSV، وفحص تواريخ مزامنة البيانات.

## القيود المهمة
- لم يُضف إرسال منشورات مجدولة تلقائيًا؛ ذلك يتطلب مهمة GitHub Actions مخصصة واختبارًا منفصلًا، وهو خارج نطاق هذا التحديث الآمن.
- لم تُضف إحصاءات زيارات وهمية؛ لوحة الإدارة تعرض فقط أعداد المنشورات وحالاتها.
- لا توجد مفاتيح API جديدة؛ الربط القائم مع OneSignal وGitHub لم يتغير.
- الأخبار مبنية على ملف `calendar-live.json` الموجود، وليس خدمة بث نتائج لحظية جديدة.
- لم نغيّر التصميم المعتمد لـ Market Pulse والأسعار المباشرة.

## اختبار بعد الرفع
- افتح `#more` واختر الأقسام الثلاثة الجديدة.
- افتح `#intelligence` وتحقق من حالات غياب البيانات.
- افتح `#academy` وأكمل اختبارًا، ثم أعد فتح الصفحة لتجربة حفظ التقدم.
- جرّب الحاسبة وغيّر المخاطرة وقيمة النقطة.
- افتح `admin.html` واتصل باستخدام رمز GitHub الحالي، ثم جرب التصدير وفحص الصحة.
