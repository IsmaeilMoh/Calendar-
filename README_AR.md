# ICT بالعربي 6.1.2 — إصلاح حجم شارت TradingView

## الإصلاح
- جعل بوكس الشارت بعرض الصفحة كاملًا في كل صفحات الأصول المالية الخمس عشرة.
- إصلاح ارتفاع الشارت الداخلي والإطار iframe؛ الآن يتمدد الشارت لملء البوكس فعليًا.
- تحديد ارتفاع متجاوب: كبير على الكمبيوتر، وأنسب على الموبايل.
- إبقاء بيانات الأسعار والتوصيات والتحليلات والأجندة دون أي تغيير.
- تحديث رقم نسخة ملفات الشارت ونقطة التخزين المؤقت (Service Worker).

## طريقة التركيب
1. فك الضغط.
2. ارفع الملفات التالية إلى **جذر مستودع GitHub** مع الحفاظ على مجلد `assets` كما هو:
   - `asset.css`
   - `asset.js`
   - `sw.js`
   - مجلد `assets` بما يحتويه من 15 صفحة HTML.
3. استبدل الملفات القديمة عند الطلب، ثم اضغط **Commit changes**.
4. افتح `assets/XAUUSD.html`، ثم جرّب Ctrl + Shift + R والتصفح على الموبايل.

**مهم:** لا ترفع ملف README إلى الموقع إن لم تكن بحاجة له، ولا تعدّل `app.js` أو `index.html` أو إعدادات OneSignal أو ملفات JSON.
